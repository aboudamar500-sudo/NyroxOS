# NyroxOS

A custom Debian 13 Live system with the LXQt desktop.

## Principles
- Keep the standard Debian Linux kernel.
- Keep the standard Debian Live boot mechanism.
- Customize the welcome screen, desktop appearance, and applications.
- Build ISO images using GitHub Actions.

The first build is a baseline image. NyroxOS branding and further
desktop customization will be added incrementally after the baseline
build succeeds.
